## Pins

Pin assignments the firmware uses for this build:

| Function | Pin |
|---|---|
| Button | PC2 |
| LED | PC1 |
| Illuminance ADC | PB6 |
| RF power amplifier | RX enable PC3, TX enable PC4 |

Notes from the board header. Where they disagree with the table above, the table is what the firmware uses:

```
 https://pvvx.github.io/ZG-223Z/

TLSR8253 512K

PC0 +LXsensor
PC1 LED to R to +BAT
PC2 Button to GND
PC3 CB2401 pin 6: RXEN
PC4 CB2401 pin 5: TXEN
PB4 R 10k to PB5
PB5 R 10k -> Raindrop-sensor to GND
PB6 -LXsensor + R 50k to GND
```

## Zigbee clusters

Set by `DEV_SERVICES` in the board header and [src/app_cfg.h](../src/app_cfg.h):

- Basic (`0x0000`), Power Configuration (`0x0001`), Poll Control (`0x0020`), OTA Upgrade (`0x0019`)
- Temperature Measurement (`0x0402`), Relative Humidity Measurement (`0x0405`), Thermostat User Interface Configuration (`0x0204`)
- Illuminance Measurement (`0x0400`), Illuminance Level Sensing (`0x0401`)
- Dehumidification Control (`0x0203`)
- On/Off (`0x0006`) as an output cluster, enabled by `USE_REMOTE_ONOFF`

Button actions, settings and default reporting are the same for every board and are described in the [main README](../README.md).

## Build

Zigbee only:

```
make -s -j VERSION_BIN=_v0140 PROJECT_NAME=ZG223Z POJECT_DEF="-DBOARD=BOARD_ZG223Z" ZNAME="HOBEIAN:ZG223Z-z"
```

Zigbee with BLE OTA (see [ZBdevices.md](../ZBdevices.md)):

```
make -s -j VERSION_BIN=_zb0018 PROJECT_NAME=ZG223Z USE_ZB=1 POJECT_DEF="-DBOARD=BOARD_ZG223Z" ZNAME="HOBEIAN:ZG223Z-z"
```
